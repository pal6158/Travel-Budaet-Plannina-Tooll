# Travel-Budaet-Plannina-Tooll
🌍 Travel Budget Planner
A simple and user-friendly web application to help users plan their travel budget by calculating expenses like transportation, accommodation, food, and more. Stay within budget and enjoy stress-free trips!

✨ Features
1. Add and categorize travel expenses

2. Set and monitor total budget

3. Real-time budget balance calculation

4. Summary of expenses (per category)

5. Responsive and easy-to-use UI

🛠️ Technologies Used
HTML5, CSS3, JavaScript

React.js (if using React)

Node.js + Express (for backend)

MongoDB (for storing user data – optional)
